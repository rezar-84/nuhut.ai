# Postmortems

One file per incident: `YYYY-MM-DD-slug.md`, from `../../templates/postmortem.md`.

**Mandatory after any S0 or S1** (`../../process/04-quality-gates.md`). Optional, and
often worth it, after a near miss.

## What makes one worth writing

The output is a change to the system, not a description of the incident. Every
postmortem ends in tracked backlog items with IDs — a postmortem with no follow-up items
either found nothing, or found something and dropped it.

Blameless means blameless about *people*, not about *causes*. "Human error" is not a
root cause; it is a prompt to ask what made the error easy and the correct action hard.
