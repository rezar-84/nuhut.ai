# Epics

One file per epic: `{{PREFIX}}-###.md`, from `../../templates/epic.md`.

An epic groups several work items under one plan, one design review, and the human
checkpoints its plan chooses. Projects that work item by item never need this folder.

Full rules: `../../process/11-epics.md`. The short form is in `../../CARD.md`.
