# Worklog archive

Older worklog entries, one file per year: `YYYY.md`.

When `../worklog.md` gets long enough that the recent entries are hard to find, move the
older ones here and leave a pointer line in `worklog.md` saying what moved and where.
Do the same for completed backlog rows.

**Nothing is deleted, only moved.** The worklog is the only place a future agent can
learn why something looks the way it does, and an entry's value is highest exactly when
it is old enough that nobody remembers the reason.

Entries keep their original IDs and dates. Do not renumber, reword, or tidy them on the
way in — an archived entry is a record of what was believed at the time, including where
that turned out to be wrong.

Full rules: `../../process/07-traceability.md`.
